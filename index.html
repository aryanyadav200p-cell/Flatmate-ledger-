DEPLOYMENT & HOUSEHOLD

Setup & sync

Prepare the same app for use on all six phones.

Household members

The six names are configured in this starter version. Member sign-in and permissions must be configured before private records can be safely shared across devices.

Cloud sync configuration

Not connected yet

This package includes a Supabase schema and setup guide. It does not silently pretend cloud sync is active. Until credentials and database policies are configured and tested, this app uses local storage.

Saving credentials alone does not complete synchronization in this starter UI. Follow README.md to configure the database, authentication and row-level security. Never put a service-role key in a public website.

Local data

This browser's records are stored locally. Export a backup before clearing data or changing devices.
